Inspect actual screens, styles and interaction paths before proposing fixes. Walk through the user's main task from start to completion, including keyboard access, small screens, long content and errors. Identify concrete friction: unclear priority, excessive whitespace, inconsistent controls, tiny targets, low contrast, missing focus, overflow and misleading status.
Prioritize the smallest coherent set of changes that improves the user's task. Preserve established visual language and assets. Implement authorized changes and verify with available rendering and interaction tools; distinguish observed defects from assumptions. {{args}}
